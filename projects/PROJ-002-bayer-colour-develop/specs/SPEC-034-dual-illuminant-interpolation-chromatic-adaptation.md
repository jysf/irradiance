# SPEC-034: **Dual-illuminant interpolation + chromatic adaptation**:

> **OUTLINE — `cycle: frame`.** This spec exists so its ID is stable and
> siblings can declare `depends_on: [SPEC-034]`. Capture **scope** (Context /
> Goal / Non-Goals) and **dependencies** only — the *approach* is designed
> just-in-time when this moves to `design`. Do not pre-design it here.

## Context

[[SPEC-033]] produces a correct colour render using a **single** illuminant's matrix.
But a DNG carries **two** calibrations — `ColorMatrix1/2` + `ForwardMatrix1/2` at
`CalibrationIlluminant1/2` (e.g. StdA ~2856 K and D65) — and the colour-correct matrix
for a given shot is **interpolated** between them by the scene's white (derived from
`AsShotNeutral`); the result must then be chromatically adapted to the sRGB white
(D50→D65). Without this, colour is only right for scenes near the one illuminant
SPEC-033 picked. This spec adds the interpolation + adaptation on top of SPEC-033's
transform, sharpening accuracy ahead of the [[SPEC-035]] ΔE check.

## Goal

Select the camera→XYZ matrix for a shot by interpolating `ColorMatrix` / `ForwardMatrix`
between `CalibrationIlluminant1/2` according to the scene white, and apply Bradford
chromatic adaptation D50→D65, verified bit-exact on analytic fixtures (known illuminants
and white → known interpolated, adapted matrix).
