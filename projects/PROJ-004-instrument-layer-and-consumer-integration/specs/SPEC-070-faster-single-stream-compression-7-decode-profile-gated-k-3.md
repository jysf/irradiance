# SPEC-070: — Faster single-stream Compression 7 decode, profile-gated: K-3 III Mono 704 ms and Typ 246 601 ms, both single scans with no restart markers, so units cannot split them; profile src/ljpeg.rs (Huffman decode, prediction), change only what the profile names; bit-exact against dnglab (SPEC-044's oracle) and every lossless-JPEG test; before/after timed.

> **OUTLINE — `cycle: frame`.** This spec exists so its ID is stable and
> siblings can declare `depends_on: [SPEC-070]`. Capture **scope** (Context /
> Goal / Non-Goals) and **dependencies** only — the *approach* is designed
> just-in-time when this moves to `design`. Do not pre-design it here.

## Context

Third spec of STAGE-020, triage item 1b in `feedback/2026-11-11-monorail-000-requests.md`.
The framing probe measured `unpack_into` at 704 ms on the K-3 III Mono and 601 ms on the
M Typ 246, both one Compression 7 strip. Their scans carry no restart interval and no RST
markers, so SPEC-068's units cannot split them. Only a faster single-stream decode helps
those cameras. Like SPEC-069, it is profile-gated.

## Goal

Make the single-stream lossless-JPEG decode in `src/ljpeg.rs` measurably faster on the
held Compression 7 files. It must stay bit-exact against dnglab (SPEC-044's oracle) and
every existing lossless-JPEG test. The before/after is recorded.
